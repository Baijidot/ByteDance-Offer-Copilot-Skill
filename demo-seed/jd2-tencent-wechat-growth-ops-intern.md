微信事业群 - 用户增长运营实习生（广州）

岗位职责：
1. 负责微信小程序/视频号相关业务的用户增长策略制定与执行，包括拉新、激活、留存全链路运营；
2. 策划并落地增长活动与私域社群运营，跟踪转化率、留存等核心指标；
3. 基于用户画像和埋点数据做用户分层与精细化运营，输出增长实验方案并做 A/B测试验证；
4. 与产品、算法、设计团队协作，推动增长需求落地；
5. 输出竞品分析与行业研究报告。

岗位要求：
1. 2026、2027 届本科及以上学历在读，能保证每周至少 4 天、连续 3 个月以上实习；
2. 具备数据分析能力，熟练使用 SQL / Python 处理数据，能用 Tableau 或 Power BI 做数据可视化；
3. 有用户运营、社群运营或增长相关实习经验者优先，有直播或视频号运营经验加分；
4. 英语六级或同等水平，能阅读英文行业报告；
5. 结构化思维好，主动、自驱，有较强的结果导向和跨部门推动能力。
