# 演示数据（fictional demo data）

**这里的所有人物与数据都是虚构的**：「林晓雨 · 产品运营实习」是为录制演示截图 / GIF 编的演示人设，
不对应任何真人。工具本身对真实输入零示例数据（见 README「去掉所有示例数据」），这套种子只用于
演示与验收时快速把界面填到「有数据」的状态。

- `resume.md` — 「林晓雨 · 产品运营实习」简历原文（粘贴或上传到引导页即可）
- `jd1-*.md` / `jd2-*.md` / `jd3-*.md` — 3 份 JD（规则匹配分分别为 85 / 66 / 21，jd3 触发学历/年限/院校三条硬门槛）
- `seed.py` — 通过真实 HTTP API 一键灌入以上简历 + 3 JD + 9 条不同状态投递记录：
    `python3 seed.py http://127.0.0.1:8000`
- `user_data/` — 灌入后 `user_data/{profile,jds,applications}.json` 的快照，
  直接拷到项目 `user_data/` 下也能复现同一演示状态（不含 settings.json）。
